# Analysis

## What an analysis is
An analysis run reports stored indicator values and their change between two years. It is descriptive only: it states no correlation, no cause, and no interpretation.

## Running an analysis
On the Analysis page, "Run an analysis" lets a Researcher choose the data class, reference or demonstration, and run and record it. A run uses values of one data class only; reference and demonstration data are never mixed.

## Reproducibility
Each run records its method and version, its parameters, every value it used with the release it came from, and a SHA-256 fingerprint of its inputs and of its result. The run's page runs it again on the values held now and says whether it is reproduced exactly, whether the inputs have changed, or whether the method has changed.

## Exports
An analysis run's page offers "Export CSV" and "Export JSON". Each export carries the run's values, their releases, and the fingerprints.
