# Fonts

Served by this application so that no page makes a request to a third party.
Each file is the variable-weight WOFF2 subset published by Fontsource, unchanged.

| Family | Fontsource package | Subsets | Licence |
|---|---|---|---|
| Inter | `@fontsource-variable/inter` 5.3.0 | latin, latin-ext, cyrillic, cyrillic-ext | SIL Open Font License 1.1 (`inter-LICENSE.txt`) |
| Source Serif 4 | `@fontsource-variable/source-serif-4` 5.3.1 | latin (normal and italic), latin-ext, cyrillic, cyrillic-ext | SIL Open Font License 1.1 (`source-serif-4-LICENSE.txt`) |
| JetBrains Mono | `@fontsource-variable/jetbrains-mono` 5.3.0 | latin, latin-ext, cyrillic | SIL Open Font License 1.1 (`jetbrains-mono-LICENSE.txt`) |

Obtained on 2026-10-30 from `cdn.jsdelivr.net/npm/<package>@<version>/files/`.
The Latin-extended and Cyrillic subsets cover Turkmen and Uzbek in Latin script
and Russian, Uzbek, and Kazakh in Cyrillic script.
